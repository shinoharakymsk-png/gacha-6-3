# 🎒 ６年３組ガチャ (6-3 Gacha)

小学校６年３組の教室や懐かしい思い出をテーマにした、カプセルトイ（ガチャガチャ）Webプラットフォームです。  
Next.js 16 (App Router) + TypeScript + Tailwind CSS + Supabase で構築され、Vercelへのデプロイに最適化されています。

---

## 🌟 主な機能

### 1. 「回す」モード（Play）
- **カプセルトイマシン演出**: ハンドル（レバー）を回すと、カラフルなカプセルがコロコロ排出されるアニメーション＆効果音（Web Audio API）。
- **単発 & 10連ガチャ**: 1回ずつじっくり回すモードと、一気に10連で引くモード。
- **カプセル開封演出**: パカッと割れるエフェクト、UR/SSR当選時の紙吹雪（confetti）＆ファンファーレ。
- **絵文字リアクション（評価）**: 出た景品に対して絵文字（👏、🤣、❤️、⭐、🔥）を押して評価・応援。
- **提供割合・ラインナップ一覧**: 排出確率（%）と全景品リストの確認モーダル。
- **ガチャ検索・カテゴリ絞り込み**: キーワード検索やカテゴリ別（学校生活、給食、放課後など）の絞り込み。

### 2. 「今日のガチャ（日替わり運勢）」🌟
- **1日1回限定のデイリーおみくじ**: 毎日サイトを最初に開いたときに「今日の運勢ガチャ」がポップアップ。
- **小学校あるある運勢**: （例：「超大吉：給食で幻の揚げパンがおかわり自由！」「中吉：理科の実験がぷるぷるスライムで大成功！」）。
- トップ黒板に「本日の運勢」と「幸運具（ラッキーアイテム）」が掲示されます。

### 3. 「作る」モード（Create）
- **オリジナルガチャ作成**:
  - ガチャ名、説明、カテゴリ、作成者名、カバーアイコン選択
  - 景品アイテムの自由追加・編集（名前、説明、レアリティ: N / R / SR / SSR / UR、出現率ウェイト、シークレット???設定）
  - **確率を100%に自動調整するボタン**
  - **お試しテストプレイ（試し回しシミュレータ）**
- **「今日の運勢」作成・追加**:
  - 運勢ランク（超大吉、大吉、凶など）、運勢メッセージ、ラッキーアイテム、出現率を設定して追加。追加した運勢は「今日の運勢ガチャ」のラインナップに即座に反映されます。

### 4. 「コレクション」モード（Collection）
- **図鑑機能**: 獲得した景品はフルカラー表示＋獲得回数バッジ。未獲得アイテムはシルエット表示。
- **コンプリート率**: 全体およびガチャごとの達成率（%）プログレスバー。

## 🚀 ローカルでの起動方法

```bash
# 依存関係のインストール（初回のみ）
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。  
※Supabaseの接続設定を行っていなくても、**高速ローカル保存モード（ブラウザLocalStorage）** で全機能が完全に動作します。

## 🗄️ Supabase連携 & Vercelデプロイ手順

### 1. Supabaseのセットアップ
1. [Supabase](https://supabase.com/) で新規プロジェクトを作成します。
2. Supabaseダッシュボードの **SQL Editor** を開きます。
3. 本プロジェクトの `supabase/schema.sql` の内容をコピー＆ペーストして実行（Run）します。
   - `gachas`, `gacha_items`, `daily_fortunes`, `item_reactions` テーブルが自動作成されます。
4. **Project Settings** > **API** から以下をコピーします：
   - `Project URL`
   - `anon / public API key`

### 2. Vercelへのデプロイ
1. GitHubリポジトリに本プロジェクトをプッシュします。
2. [Vercel](https://vercel.com/) でリポジトリをインポートします。
3. **Environment Variables** に以下を追加します：
   - `NEXT_PUBLIC_SUPABASE_URL` = あなたのSupabase Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = あなたのSupabase anon API key
4. **Deploy** をクリックすると、数分で全世界に公開されます！

※アプリ内右上の「データベース設定（歯車アイコン）」から、ブラウザ上で直接Supabase接続をテストすることも可能です。
